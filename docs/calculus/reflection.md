# Reflection

**Status: Characterised.** `Contract.lean` arrives in T3 and is honest about being a
characterisation rather than a proof.

## What it fixes

The document round trip. A document this library writes, read back by the schema it was written
against, is the document — and the guard for that is not a theorem.

## The claim

**A committed document, read back, is the document.** For each of the five document kinds
(`ledger`, `derivation`, `overlay`, `annotation_request`, `narrative`) the JSON Schema is generated
from the pydantic model, the golden fixture is generated by writing that model, and reading the
fixture back yields an equal model.

## Why the real guard is elsewhere

**`tests/ledger/test_contract.py` is the guard, and it already exists.** It fails when either the
generated schema or the golden fixture goes stale against the hand-maintained description, which
is the property a reader actually needs.

A theorem here would be a statement about generated files rather than about a Lean object, and
making it a Lean object would mean porting the pydantic models into Lean — at which point the
theorem is about the port. That is the same failure this section refuses everywhere else: a proof
about a re-implementation, dressed as a proof about the library.

So the layer is **characterised**: the claim describes what the contract does, nothing this
repository can do would violate it without `make contract` failing first, and it is deliberately
not proved.

## What it is about in the tree

| The claim's subject | The tree |
|---|---|
| one hand-maintained description | `src/chainlens/ledger/schema.py::render_schemas` |
| the staleness gate | `tests/ledger/test_contract.py`, run by `make contract` |
| the fixture | `tests/ledger/fixtures.py` |

The arrangement is worth naming because it is the third of its kind in this repository — a
hand-maintained description, generated artefacts, and a test that fails on a diff. `make contract`
regenerates the wire schema; `make docs-reference` regenerates the API reference;
`make vocabulary` regenerates [the vocabulary table](./vocabulary.md)'s artefacts. Each is a
convenience, and the *guard* is always the test, because a convenience somebody has to remember to
run is not a check.
